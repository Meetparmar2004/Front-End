Que - What are lifecycle methods in React class components?
      Describe the phases of a component’s lifecycle.

Ans -   --> Lifecycle methods : -> In React class components, lifecycle methods are special methods that are automatically called at different stages of a component’s life.
                                -> These methods allow devlopers to control what happens when a component is created, updated, or removed from the screen.

        --> Phases of a Component’s Lifecycle : 

                1) Mounting Phase : -> This phase occurs when the component is created and inserted into the DOM.
                                    > constructor()
                                    > render()
                                    > componentDidMount()

                2) Updating Phase : -> This phase occurs when the component is updated, usually due to changes in state or props.
                                    > render()
                                    > componentDidMount()
                
                3) Unmounting Phase : -> This phase occurs when the component is removed from the DOM.
                                      > componentDidMount()
