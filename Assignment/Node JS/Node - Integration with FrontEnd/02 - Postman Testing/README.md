# 02 - Postman Testing

This folder is my work for the Postman tasks.

## Files

- `FoodieApp APIs.postman_collection.json` — the collection I exported from Postman (Task 5).
- `testing-notes.txt` — what I saw for each request (status and body).
- `.gitignore` — ignores `node_modules` and local files.

## How to open it

1. Install Postman from https://www.postman.com/downloads/ if it is not installed yet.
2. Open Postman and click Import.
3. Choose `FoodieApp APIs.postman_collection.json`.
4. Open the FoodieApp APIs collection and click Send on each request.

The collection has three requests:

- Get all posts (GET)
- Add a new user (POST)
- Update a post (PUT)
